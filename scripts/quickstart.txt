小鲸鱼桌宠 WhalePet —— 使用说明（先看这个）
============================================

1. 双击 WhalePet.exe 即可运行，不需要安装 Python / Node / Qt。

2. 首次启动会让你填 DeepSeek API Key（只保存在你自己电脑上，不会上传）。
   小鲸鱼会浮在桌面右下角：点它弹泡泡，右键（或右上角菜单按钮）打开设置面板。
   角色、音效、泡泡内容、吸附方式、记账等全部在挂件自己的菜单里改。

3. 想把客户端用量也统计进"每轮消耗"：把客户端的 base_url 指到
   http://127.0.0.1:11434/v1 （端口可在托盘菜单 →「设置」里改）。

4. 数据位置：默认在 %APPDATA%\WhalePet（配置、账本、角色图、音效、泡泡配置）。
   想"整个文件夹拷走即用"：在 exe 同目录放一个空的 portable.flag 文件，
   数据就会落在 exe 同级的 WhalePetData\ 目录里，换机器直接带着走。

5. 启动速度：第一次启动要解压内置运行时，约 5~10 秒；之后每次约 5 秒。
   启动后看右下角系统托盘的小鲸鱼图标，托盘菜单里有显示/隐藏、设置、关于、退出。

6. 退出与卸载：托盘图标右键 →「退出」；卸载就是删掉 exe 和上面的数据目录。

7. 杀软误报：程序用 PyInstaller 打包且内嵌 Node 运行时，个别杀软会误报，
   加白名单即可；整套源码与构建脚本都在工程里，可以自行复核后再打包。

8. 系统要求：64 位 Windows 10 1809+ / Windows 11。

9. 隐私：所有数据都在本机；余额与用量查询只走你自己填的接口地址；
   程序默认不向任何第三方上传数据。
